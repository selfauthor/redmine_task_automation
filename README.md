**Плагин для автоматического создания задач по расписанию в Redmine.**

---

## 📋 Описание

Плагин создаёт задачи по расписанию на основе шаблонов. Работает в фоновом режиме через cron, не требует постоянного участия после настройки.

**Решаемые проблемы:**
- Пропуск сроков создания задач
- Ошибки при ручном создании
- Отсутствие стандартизации
- Высокая нагрузка на руководителей

## 📦 Установка

```bash
cd /var/www/redmine/plugins
git clone https://github.com/selfauthor/redmine_task_automation.git
cd /var/www/redmine
touch tmp/restart.txt
```

После перезапуска в **Администрирование** появится раздел «Автоматизация задач».

## ⚙️ Настройка

### Краткая инструкция

1. Создайте пользовательские поля (см. [docs/CONFIGURATION.md](docs/CONFIGURATION.md))
2. Создайте 2 трекера для шаблонов
3. Перейдите в **Администрирование → Автоматизация задач**
4. Укажите проект, пользователя и трекеры
5. Настройте запуск через cron

```bash
0 8 * * * cd /var/www/redmine && bundle exec rake redmine:task_automation:process RAILS_ENV=production
```

> **Важно:** Полная таблица полей и подробная инструкция по настройке находятся в документации.
