# Вклад в проект Redmine Task Automation

Мы приветствуем вклад в развитие плагина! Этот документ описывает правила и рекомендации для внесения изменений.

## Как сообщить об ошибке

### Перед созданием Issue

1. **Проверьте существующие Issue** — возможно, проблема уже известна
2. **Обновитесь до последней версии** — ошибка может быть уже исправлена
3. **Проверьте логи** — соберите информацию об ошибке

### Создание отчёта об ошибке

При создании Issue укажите:

- **Заголовок:** Краткое описание проблемы
- **Версия Redmine:** Например, 6.0.7
- **Версия плагина:** Например, 1.0.0
- **Версия Ruby:** Например, 3.2.9
- **Операционная система:** Например, CentOS Stream
- **Шаги воспроизведения:**
  1. Шаг 1
  2. Шаг 2
  3. ...
- **Ожидаемый результат:** Что должно произойти
- **Фактический результат:** Что происходит на самом деле
- **Логи:** Фрагменты из `log/task_automation.log`
- **Скриншоты:** Если применимо

### Пример хорошего отчёта

```
Заголовок: Ошибка при создании задачи с пустым описанием

Версия Redmine: 6.0.7
Версия плагина: 1.0.0
Ruby: 3.2.9
ОС: Ubuntu 22.04

Шаги воспроизведения:
1. Создать шаблон задачи
2. Оставить поле "Описание" пустым
3. Запустить плагин

Ожидаемый результат: Задача создаётся с пустым описанием
Фактический результат: Ошибка валидации, задача не создаётся

Логи:
[2026-03-24 08:00:15] [ERROR] Ошибка валидации: Описание не может быть пустым
```

## Как предложить улучшение

### Создание предложения

При создании Issue с меткой «enhancement» укажите:

- **Заголовок:** Краткое описание предложения
- **Описание:** Подробное описание новой функции
- **Обоснование:** Зачем это нужно
- **Примеры использования:** Как это будет работать
- **Альтернативы:** Рассмотренные альтернативные решения

## Как внести изменения (Pull Request)

### Требования к коду

1. **Стиль кода:**
   - Следуйте Ruby Style Guide
   - Используйте 2 пробела для отступов
   - Максимальная длина строки: 100 символов
   - Именуйте переменные понятно

2. **Тестирование:**
   - Протестируйте изменения на тестовом окружении
   - Проверьте работу с разными версиями Redmine
   - Убедитесь, что нет регрессий

3. **Документация:**
   - Обновите документацию, если изменился функционал
   - Добавьте комментарии к сложному коду
   - Обновите CHANGELOG.md

### Процесс создания PR

1. **Fork репозитория**
   ```bash
   # Создайте fork на GitHub
   ```

2. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/YOUR_USERNAME/redmine_task_automation.git
   cd redmine_task_automation
   ```

3. **Создайте ветку**
   ```bash
   git checkout -b feature/your-feature-name
   # или
   git checkout -b fix/your-bugfix-name
   ```

4. **Внесите изменения**
   - Пишите атомарные коммиты
   - Используйте понятные сообщения коммитов

5. **Закоммитьте изменения**
   ```bash
   git add .
   git commit -m "Описание изменений"
   ```

6. **Отправьте в репозиторий**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Создайте Pull Request**
   - Перейдите на GitHub
   - Нажмите «New Pull Request»
   - Выберите вашу ветку
   - Заполните описание

### Шаблон Pull Request

```markdown
## Описание
Краткое описание изменений

## Тип изменений
- [ ] Исправление ошибки
- [ ] Новая функция
- [ ] Улучшение существующей функции
- [ ] Обновление документации
- [ ] Рефакторинг

## Связанные Issue
Closes #123

## Тестирование
Опишите, как тестировали изменения

## Чек-лист
- [ ] Код соответствует стилю
- [ ] Добавлены/обновлены тесты
- [ ] Обновлена документация
- [ ] Протестировано на Redmine 5.0.0+
- [ ] Нет предупреждений в логах
```

## Где что менять

### Добавление новой функции

1. **Модель:** `app/models/task_automation/`
2. **Контроллер:** `app/controllers/` (если нужен интерфейс)
3. **Представление:** `app/views/` (если нужен UI)
4. **Локализация:** `config/locales/ru.yml` и `en.yml`

### Исправление ошибки

1. Найдите источник ошибки в логах
2. Определите файл, где происходит ошибка
3. Внесите исправление
4. Протестируйте

### Добавление поля

1. **Configuration:** `app/models/task_automation/configuration.rb`
2. **Processor:** `app/models/task_automation/task_processor.rb`
3. **Локализация:** `config/locales/*.yml`
4. **Документация:** `docs/CONFIGURATION.md`

## Тестирование

### Локальное тестирование

1. **Установите тестовый Redmine**
   ```bash
   # Установите Redmine 6.0.7
   ```

2. **Установите плагин**
   ```bash
   cd /path/to/redmine/plugins
   git clone /path/to/your/fork redmine_task_automation
   ```

3. **Запустите Redmine**
   ```bash
   rails server
   ```

4. **Протестируйте изменения**

### Тестирование cron

```bash
# Ручной запуск
cd /var/www/redmine
bundle exec rake redmine:task_automation:process RAILS_ENV=development

# Проверка логов
tail -f log/task_automation.log
```
