# Логирование плагина Redmine Task Automation

## Журналы плагина

### Основной журнал

**Расположение:** `log/task_automation.log`

```bash
tail -f /var/www/redmine/log/task_automation.log
```

### Журнал cron

**Расположение:** `/var/www/cronlog/task_automation.log` (или указанный в crontab)

### Журнал Redmine

**Расположение:** `log/production.log`

```bash
tail -f /var/www/redmine/log/production.log
```

## Формат записей

```
[2026-03-24 08:00:12] [INFO] Запуск обработки задач-шаблонов
│              │            │
│              │            └─ Сообщение
│              └─ Уровень
└─ Дата и время
```

## Уровни логирования

| Уровень | Когда используется | Цвет |
|---------|-------------------|------|
| **INFO** | Штатное выполнение операций | 🔵 Синий |
| **WARNING** | Внештатные события, не мешающие созданию задачи | 🟡 Жёлтый |
| **ERROR** | Ошибки, препятствующие созданию задачи | 🔴 Красный |

### INFO — информационные сообщения

```
[2026-03-24 08:00:12] [INFO] Запуск обработки задач-шаблонов

[2026-03-24 08:00:14] [INFO] Найдено задач-триггеров: 2
[2026-03-24 08:00:15] [INFO] Создана задача #500 для исходной задачи #100
[2026-03-24 08:00:16] [INFO] Создана задача #501 для исходной задачи #101
[2026-03-24 08:00:17] [INFO] Обработка завершена: обработано=2, создано=2, ошибок=0
```

### WARNING — предупреждения

```
[2026-03-24 08:00:15] [WARNING] Поле "Приоритет" не найдено в задаче #100
[2026-03-24 08:00:16] [WARNING] Срок завершения подзадачи превышает срок родительской задачи

```

### ERROR — ошибки

```
[2026-03-24 08:00:13] [ERROR] Проект назначения не найден: "Неверное название"
[2026-03-24 08:00:14] [ERROR] Трекер не доступен в проекте: "Bug"
[2026-03-24 08:00:15] [ERROR] Ошибка валидации: Тема не может быть пустой
```

## Что записывается в лог

### При запуске

- Время начала обработки
- Загруженные настройки
- Количество найденных задач-триггеров

### При обработке

- Создание каждой задачи (ID созданной задачи, ID шаблона)
- Ошибки валидации
- Предупреждения о проблемах

### При завершении

- Количество обработанных задач
- Количество успешно созданных задач
- Количество ошибок
- Общее время выполнения

## Уведомления администраторам

Если в журнале появились сообщения типа **WARNING** или **ERROR**, на адреса пользователей с правами администратора автоматически отправляется email с уведомлениями.

### Содержимое письма

- Дата и время возникновения
- Уровень сообщения
- Текст ошибки/предупреждения
- Ссылка на проблемную задачу (если применимо)

> **Важно:** Даже при сообщении типа WARNING необходимо вмешательство человека для исправления ситуации и предотвращения подобных случаев в будущем.

## Анализ логов

### Поиск ошибок

```bash
grep "ERROR" /var/www/redmine/log/task_automation.log
```

### Поиск предупреждений

```bash
grep "WARNING" /var/www/redmine/log/task_automation.log
```

### Просмотр за определённую дату

```bash
grep "2026-03-24" /var/www/redmine/log/task_automation.log
```

### Подсчёт ошибок

```bash
grep -c "ERROR" /var/www/redmine/log/task_automation.log
```

### Последние 50 записей

```bash
tail -50 /var/www/redmine/log/task_automation.log
```

### Мониторинг в реальном времени

```bash
tail -f /var/www/redmine/log/task_automation.log
```

## Ротация логов

Для предотвращения разрастания логов настройте ротацию:

### Создание конфигурации logrotate

```bash
sudo nano /etc/logrotate.d/redmine-task-automation
```

### Содержимое файла

```
/var/www/redmine/log/task_automation.log {
    daily
    rotate 30
    compress
    delaycompress
    notifempty
    create 0644 www-data www-data
    postrotate
        touch /var/www/redmine/tmp/restart.txt
    endscript
}
```

### Параметры ротации

- `daily` — ежедневная ротация
- `rotate 30` — хранить 30 архивов
- `compress` — сжимать старые логи
- `delaycompress` — сжимать со второй ротации
- `notifempty` — не ротировать пустые файлы
- `create 0644 www-data www-data` — права и владелец нового файла

## Настройка уровня логирования

В файле `config/environment.rb` можно изменить уровень детализации:

```ruby
# Для отладки
Rails.logger.level = Logger::DEBUG

# Стандартный уровень
Rails.logger.level = Logger::INFO

# Только ошибки
Rails.logger.level = Logger::ERROR
```

## Экспорт логов

### В файл

```bash
cat /var/www/redmine/log/task_automation.log > task_automation_export.log
```

### В архив

```bash
tar -czf logs_$(date +%Y%m%d).tar.gz /var/www/redmine/log/task_automation.log
```

## Очистка логов

### Очистить файл

```bash
> /var/www/redmine/log/task_automation.log
```

### Удалить старые логи

```bash
find /var/www/redmine/log -name "task_automation.log.*" -mtime +30 -delete
```
