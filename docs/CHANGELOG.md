# История версий (Changelog)

## Версия 1.0.0 (24.03.2026)

### ✨ Добавлено

- **Создание задач по расписанию**
  - Поддержка периодичности: день, неделя, месяц, год
  - Привязка к дням недели
  - Учёт рабочих и выходных дней
  - Гибкая настройка расписания

- **Шаблоны задач**
  - Создание шаблонов основных задач
  - Создание шаблонов подзадач
  - Цепочки подготовительных задач
  - Промежуточные сроки выполнения

- **Заполнение полей**
  - Проект назначения
  - Трекер
  - Назначение и наблюдатели
  - Приоритет и другие стандартные поля
  - Пользовательские поля через описание

- **Управление расписанием**
  - Интервалы повторения
  - Порядковые номера дней в месяце
  - Выбор дней недели
  - Выбор месяцев для годового расписания
  - Создание задач заранее

- **Автоматизация**
  - Запуск через cron
  - Ежедневная проверка шаблонов
  - Ручной запуск через интерфейс
  - Тестирование настроек

- **Логирование**
  - Подробный журнал работы
  - Уровни: INFO, WARNING, ERROR
  - Автоматические уведомления администраторам
  - Отчёты о выполнении

- **Безопасность**
  - Работа от имени системного пользователя
  - Соблюдение прав доступа Redmine
  - Стандартные workflow и статусы
  - Ограничения для разных ролей

### 🔧 Технические улучшения

- **Архитектура MVC**
  - Контроллеры для управления настройками
  - Модели для бизнес-логики
  - Представления для интерфейса
  - Mailer для email-уведомлений

- **Структура кода**
  - Модульная организация
  - Service-класс для координации
  - TaskProcessor для обработки задач
  - Configuration для работы с настройками

- **Интеграция**
  - Rake-задачи для cron
  - Интеграция с настройками Redmine
  - Использование стандартных моделей Issue, Project, CustomField

### 📄 Документация

- Подробное руководство пользователя
- Инструкция по установке
- Руководство по настройке
- Описание системы логирования

### 🛡 Защита от дубликатов

- Одна исходная задача → одна целевая задача за запуск
- Повторный запуск в тот же день не создаёт дубликат
- Использование транзакций базы данных
- Автоматическое обновление даты следующего выполнения

### ⚙️ Настройки

- Централизованное управление
- Страница настроек в административном разделе
- Тестирование конфигурации
- Ручной запуск из интерфейса

### 📊 Временные характеристики

- Частота запуска: настраивается в cron (рекомендуется 1 раз в день)
- Время выполнения: 1-30 секунд (зависит от количества задач)
- Обработка одной задачи: ~50–200 мс
- Рекомендуется до 1000 задач за запуск
