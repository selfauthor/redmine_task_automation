## О плагине

**Redmine Task Automation** — плагин для автоматического создания задач по расписанию на основе специальных шаблонов в системе управления проектами Redmine.

### Основные возможности

✅ Создание задач по расписанию (день, неделя, месяц, год)  
✅ Гибкая настройка периодичности с привязкой к дням недели  
✅ Заполнение любого количества полей задачи  
✅ Создание цепочек подзадач с промежуточными сроками  
✅ Централизованное управление настройками  
✅ Подробное логирование всех операций  
✅ Контроль доступа и безопасность Redmine

### Решаемые проблемы

- Пропуск сроков создания задач
- Ошибки при копировании данных
- Отсутствие стандартизации процессов
- Высокая нагрузка на руководителей проектов
