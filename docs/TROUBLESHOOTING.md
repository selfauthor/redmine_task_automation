# Решение проблем (Troubleshooting)

## Диагностика установки

### Проблема: Ошибка после установки плагина

**Симптомы:**
- Страницы Redmine не открываются
- Ошибка 500 Internal Server Error

**Решение:**

1. **Откат изменений:**
   ```bash
   rm -rf /var/www/redmine/plugins/redmine_task_automation
   touch /var/www/redmine/tmp/restart.txt
   ```

2. **Поиск ошибки:**
   ```bash
   tail -100 /var/www/redmine/log/production.log
   ```

3. **Проверка зависимостей:**
   ```bash
   cd /var/www/redmine
   bundle check
   ```

---

### Проблема: Плагин не отображается в списке модулей

**Симптомы:**
- Файлы скопированы
- Redmine перезапущен
- Плагин не виден в «Администрирование → Модули»

**Решение:**

1. **Проверьте наличие init.rb:**
   ```bash
   ls -la /var/www/redmine/plugins/redmine_task_automation/init.rb
   ```

2. **Проверьте права доступа:**
   ```bash
   chmod -R 755 /var/www/redmine/plugins/redmine_task_automation
   chown -R www-data:www-data /var/www/redmine/plugins/redmine_task_automation
   ```

3. **Перезапустите Redmine:**
   ```bash
   touch /var/www/redmine/tmp/restart.txt
   ```

---

## Проблемы с настройкой

### Проблема: Ошибка при тестировании настроек

**Симптомы:**
- Кнопка «Тестировать» показывает ошибку
- Трекеры не найдены

**Решение:**

1. **Проверьте наличие трекеров:**
   - Перейдите в проект шаблонов
   - Убедитесь, что создано 2 трекера

2. **Проверьте поля трекеров:**
   - Откройте настройки каждого трекера
   - Убедитесь, что добавлены все необходимые пользовательские поля

3. **Проверьте права пользователя:**
   - У пользователя должны быть права на чтение проектов
   - У пользователя должны быть права на создание задач

---

### Проблема: Поля не создаются

**Симптомы:**
- Ошибка при создании пользовательских полей
- Поля не сохраняются

**Решение:**

1. **Проверьте название поля:**
   - Название должно точно совпадать с таблицей в документации
   - Проверьте регистр букв

2. **Проверьте тип поля:**
   - Убедитесь, что выбран правильный тип (Текст, Целый, Список и т.д.)

3. **Проверьте регулярное выражение:**
   - Для числовых полей укажите правильное regex
   - Пример: `^[1-9]\d*$` для положительных чисел

---

## Проблемы с cron

### Проблема: Cron не запускается

**Симптомы:**
- Задачи не создаются автоматически
- В логах cron нет записей

**Решение:**

1. **Проверьте статус cron:**
   ```bash
   service cron status
   ```

2. **Проверьте установленные задачи:**
   ```bash
   crontab -l
   ```

3. **Проверьте логи cron:**
   ```bash
   grep CRON /var/log/syslog
   ```

4. **Перезапустите cron:**
   ```bash
   service cron restart
   ```

---

### Проблема: Ошибка bundle: command not found

**Симптомы:**
- В логе cron: `bundle: command not found`

**Решение:**

Укажите полный путь к bundle:

```bash
0 8 * * * cd /var/www/redmine; /opt/ruby-3.2/bin/bundle exec rake redmine:task_automation:process RAILS_ENV=production >> /var/www/cronlog/task_automation.log 2>&1
```

Чтобы найти путь:
```bash
which bundle
```

---

### Проблема: Permission denied

**Симптомы:**
- Ошибка доступа к файлам

**Решение:**

```bash
chown -R www-data:www-data /var/www/redmine
chmod -R 755 /var/www/redmine/plugins/redmine_task_automation
```

## Проблемы с созданием задач

### Проблема: Задачи не создаются

**Симптомы:**
- Плагин запускается
- В логе нет ошибок
- Задачи не появляются

**Решение:**

1. **Проверьте дату следующего выполнения:**
   - Дата должна быть в прошлом или сегодня
   - Если дата в будущем — шаблон не активируется

2. **Проверьте статус шаблона:**
   - Статус должен быть «открыт»
   - Закрытые шаблоны не обрабатываются

3. **Проверьте дату начала и срок завершения:**
   - Дата начала не должна быть в прошлом (если шаблон новый)
   - Срок завершения не должен быть прошлой датой

4. **Проверьте логи:**
   ```bash
   tail -100 /var/www/redmine/log/task_automation.log
   ```

---

### Проблема: Создаются дубликаты задач

**Симптомы:**
- По одному шаблону создаётся несколько одинаковых задач

**Решение:**

1. **Проверьте механизм защиты:**
   - После создания задачи поле «Дата следующего выполнения» должно измениться
   - Проверьте, что транзакции работают корректно

2. **Проверьте ручной запуск:**
   - Не запускайте плагин вручную, если он уже работает автоматически

3. **Проверьте cron:**
   - Убедитесь, что cron не запускает несколько экземпляров
   ```bash
   ps aux | grep rake
   ```

---

### Проблема: Ошибка валидации при создании задачи

**Симптомы:**
- В логе: `[ERROR] Ошибка валидации: ...`

**Решение:**

1. **Проверьте обязательные поля:**
   - Тема задачи не пустая
   - Проект назначения существует
   - Трекер доступен в проекте

2. **Проверьте права пользователя:**
   - Пользователь имеет права на создание задач в целевом проекте
   - Трекер доступен для пользователя

3. **Проверьте workflow:**
   - Статус по умолчанию разрешён для трекера
   - Переходы статусов настроены корректно

---

### Проблема: Неправильное расписание

**Симптомы:**
- Задачи создаются не в те дни
- Расписание не соответствует настройкам

**Решение:**

1. **Проверьте поле «Дата следующего выполнения»:**
   - Это базовая дата для расчёта следующего запуска
   - Если дата не соответствует расписанию, плагин скорректирует её

2. **Проверьте параметры расписания:**
   - Интервал > 0
   - Единица интервала выбрана корректно
   - Дни повторения соответствуют единице интервала

3. **Проверьте таблицу примеров:**
   - Сверьтесь с [документацией по расписанию](USAGE.md#гибкий-способ-привязка-к-дню-неделимесяцу)

## Проблемы с подзадачами

### Проблема: Подзадачи не создаются

**Симптомы:**
- Основная задача создаётся
- Подзадачи не появляются

**Решение:**

1. **Проверьте трекер подзадач:**
   - Трекер должен иметь поле «Родительская задача»
   - Трекер должен быть доступен в проекте

2. **Проверьте порядковые номера:**
   - У всех подзадач должны быть заполнены порядковые номера
   - Номера должны быть > 0

3. **Проверьте логи на предупреждения:**
   ```bash
   grep "WARNING" /var/www/redmine/log/task_automation.log
   ```

---

### Проблема: Неправильные даты подзадач

**Симптомы:**
- Даты подзадач не соответствуют ожидаемым
- Подзадачи перекрываются

**Решение:**

1. **Проверьте порядковые номера:**
   - Подзадачи с одинаковым номером выполняются параллельно
   - Следующий номер начинается после завершения предыдущего

2. **Проверьте срок выполнения:**
   - Срок выполнения должен быть >= 0
   - Сумма сроков не должна превышать срок родительской задачи

---

## Проблемы с логами

### Проблема: Логи не записываются

**Симптомы:**
- Файл лога не создаётся
- Нет записей в логе

**Решение:**

1. **Проверьте права на запись:**
   ```bash
   ls -la /var/www/redmine/log/
   chmod 755 /var/www/redmine/log
   chown www-data:www-data /var/www/redmine/log
   ```

2. **Проверьте место на диске:**
   ```bash
   df -h /var/www/redmine/log
   ```

3. **Проверьте конфигурацию Redmine:**
   ```bash
   cat /var/www/redmine/config/environment.rb | grep logger
   ```

---

### Проблема: Лог слишком большой

**Симптомы:**
- Файл лога занимает много места
- Redmine работает медленно

**Решение:**

1. **Настройте ротацию логов:**
   См. [документацию по логированию](LOGGING.md#ротация-логов)

2. **Очистите старые логи:**
   ```bash
   > /var/www/redmine/log/task_automation.log
   ```
