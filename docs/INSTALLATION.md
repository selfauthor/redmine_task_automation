# Установка плагина Redmine Task Automation

## Требования к системе

| Компонент | Минимальная версия | Проверенные версии |
|-----------|-------------------|-------------------|
| Redmine | 5.0.0 | 5.0.0 – 6.0.7 |
| Ruby | 3.0.0 | 3.2.9 |
| База данных | MySQL 5.7 / MariaDB 10.3 | MariaDB 10.11 |
| ОС | Linux | CentOS, Ubuntu, Debian |

## Шаг 1: Подготовка

### Резервное копирование

Перед установкой плагина **рекомендуется сделать копию всей папки redmine**. Это не обязательное, но желательное требование, т.к. плагин при установке не изменяет никакие общие файлы.

```bash
cp -r /var/www/redmine /var/www/redmine.backup
```

### Проверка совместимости

Убедитесь, что ваша система соответствует минимальным требованиям:

```bash
# Проверка версии Redmine
cat /var/www/redmine/REDMINE_VERSION

# Проверка версии Ruby
ruby -v
```

## Шаг 2: Скачивание плагина

### Вариант 1: Git clone (рекомендуется)

```bash
cd /var/www/redmine/plugins
git clone https://github.com/selfauthor/redmine_task_automation.git
```

### Вариант 2: Загрузка архива

1. Скачайте архив с [GitHub](https://github.com/selfauthor/redmine_task_automation)
2. Распакуйте в папку `plugins`:

```bash
cd /var/www/redmine/plugins
unzip /path/to/redmine_task_automation.zip
```

## Шаг 3: Проверка установки файлов

После размещения файлов должен существовать файл:

```bash
ls -la /var/www/redmine/plugins/redmine_task_automation/init.rb
```

## Шаг 4: Установка зависимостей

Перейдите в корневую папку Redmine и установите зависимости:

```bash
cd /var/www/redmine
bundle install
```

## Шаг 5: Перезапуск Redmine

После копирования файлов необходимо перезапустить Redmine:

```bash
touch tmp/restart.txt
```

После этого вызовите любую страницу Redmine в браузере.

## Шаг 6: Проверка установки

### Успешная установка

Если установка прошла успешно:

1. Зайдите на страницу **«Администрирование»**
2. В списке разделов должен появиться пункт **«Автоматизация задач»**
3. На странице **«Администрирование → Модули»** появится информация об установленном плагине

### Диагностика ошибок

Если после перезапуска Redmine при показе любой страницы появляется ошибка:

1. **Удалите папку плагина:**
   ```bash
   rm -rf /var/www/redmine/plugins/redmine_task_automation
   ```

2. **Перезапустите Redmine:**
   ```bash
   touch tmp/restart.txt
   ```

3. **Удостоверьтесь, что система снова работает**

4. **Найдите ошибку в логах:**
   ```bash
   tail -100 /var/www/redmine/log/production.log
   ```

5. **Если устранить ошибку самостоятельно не удалось**, свяжитесь с разработчиком плагина

## Шаг 7: Дальнейшие действия

После успешной установки перейдите к [настройке плагина](CONFIGURATION.md).
